## ⚡ QUICK REFERENCE (COPIE/COLE)

FUNÇÃO HELPER (Adicione ao app.js):
─────────────────────────────────────
async function getCurrentUserId() {
    if (!supabase) return null;
    const { data: { user } } = await supabase.auth.getUser();
    return user?.id || null;
}

PADRÃO DE INSERÇÃO (Use em .insert()):
──────────────────────────────────────
const userId = await getCurrentUserId();
if (!userId) {
    showToast('Erro: Não autenticado', 'error');
    return;
}

const { data, error } = await supabase
    .from('tabela')
    .insert([{ 
        user_id: userId,      // ← SEMPRE ADICIONE
        outros_campos: valor
    }])
    .select();

## ⚠️ ERROS COMUNS

Erro: "policy already exists"
└─ Solução: Limpe SQL Editor e rode novamente

Erro: "new row violates row-level security policy"
└─ Solução: user_id não está sendo passado no .insert()
   Verifique APP_JS_RLS_FIXES.md e adicione user_id

Erro: "Unable to read from table"
└─ Solução: Você não está autenticado ou tabela sem dados
   Faça login e crie um novo dado

Dados aparecem vazios
└─ Normal! Usuário novo não tem dados criados ainda
   Crie uma nova mensagem/áudio/mídia
